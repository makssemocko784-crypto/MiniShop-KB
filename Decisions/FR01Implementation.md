# Реалізація FR-01

FR-01 з `docs/app-requirements.md`: додавання товару з назвою, кількістю, автоматичним унікальним ID та початковим статусом «Не придбано».

## Перевірена реалізація

- `shop.py`, `add_product(products, name, quantity)`: назва має бути рядком і непорожньою після `strip()`; зберігається без крайніх пробілів.
- Кількість має бути додатним `int`; значення `bool`, рядки, дробові числа, нуль та від’ємні числа відхиляються через `ValueError`.
- ID дорівнює найбільшому наявному ID плюс один; для порожнього списку — 1. Унікальність нового ID забезпечується для коректного вхідного списку.
- Новий товар має поля `id`, `name`, `quantity`, `status` зі статусом «Не придбано». Функція повертає новий список, не змінюючи вхідний.
- `main.py`, `main()`: викликає додавання та збереження; при некоректній назві або кількості показує помилку без збереження й зміни поточного списку.

## Перевірка

Виконано `.venv/Scripts/python.exe -B -m pytest -q -p no:cacheprovider tests/test_shop.py`.

Результат: **20 passed in 0.04s**. Перевірено додавання, нормалізацію назви, унікальність ID, початковий статус, відхилення некоректних даних і відсутність автозбереження при помилці вводу. Початкова спроба запуску системним Python була невдалою: `No module named pytest`; успішний запуск виконано у `.venv`.

## Межі документування

`shop.py`, `main.py`, `storage.py` і `tests/` на момент перевірки є невідстежуваними файлами Git; відповідні робочий та staged diff порожні. Задокументовано поточну реалізацію FR-01, без тверджень про попередню поведінку чи історичний коміт. Код і тести під час документування не змінювалися.
