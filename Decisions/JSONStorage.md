# Використання JSON для збереження даних

## Контекст

Застосунок MiniShop потребує локального збереження списку покупок між запусками програми.

## Прийняте рішення

Використовувати формат JSON для збереження даних у локальному файлі.

## Обґрунтування

- JSON підтримується стандартною бібліотекою Python.
    
- Формат простий для читання та редагування.
    
- Не потребує встановлення системи керування базами даних.
    
- Підходить для невеликого навчального застосунку.
    

## Розглянуті альтернативи

- SQLite — забезпечує структуроване зберігання, але є надлишковим для одного списку покупок.
    
- CSV — простий формат, проте менш зручний для збереження структурованих об'єктів.
    

## Наслідки рішення

Застосунок використовуватиме один локальний JSON-файл. У разі збільшення обсягу даних може виникнути потреба в іншому способі збереження.

## Зв'язки

- Рішення визначає реалізацію [[DataStorage]].
    
- Формат використовується для збереження [[ShoppingList]].
    
- Дані містять об'єкти [[Product]].
