# FR-07: фільтрація товарів за статусом

## Фактичні зміни

- `shop.py`: додано `filter_products(products, status)` для статусів «Не придбано» та «Придбано». Функція повертає новий список зі збереженням порядку товарів і всіх полів; вихідний список не змінює. Недопустимий статус відхиляється через `ValueError` з українським повідомленням.
- `main.py`: додано пункт меню `4` для фільтрації. Збіги відображаються через `show_products`; за відсутності збігів виводиться повідомлення. Поточний список не підміняється, автозбереження не викликається. Помилка статусу обробляється без завершення роботи.
- `tests/test_filter_products.py`: додано 20 pytest-перевірок FR-07 — обидва статуси, порядок і поля, порожній список, відсутність збігів, незмінність даних, некоректні статуси, консольний сценарій, відсутність збереження та додавання після фільтрації.

