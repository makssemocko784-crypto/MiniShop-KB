# Статус покупки (Purchase Status)

Статус покупки — характеристика товару, яка визначає, чи був він придбаний користувачем.

## Можливі значення

- **Не придбано** — товар запланований для покупки.
    
- **Придбано** — товар уже куплений.
    

## Правила

- Новий товар отримує статус «Не придбано».
    
- Користувач може змінювати статус товару за його ID.
    
- Статус використовується для фільтрації списку.
    
- Зміна статусу автоматично зберігається у JSON.
    

## Зв'язки

- Статус є атрибутом [[Product]].
