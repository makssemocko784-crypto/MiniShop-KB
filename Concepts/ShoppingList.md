# Список покупок (Shopping List)

Список покупок — основна структура даних застосунку MiniShop, яка містить товари, заплановані користувачем для придбання.

## Основні характеристики

- Застосунок підтримує один список покупок.
    
- Список може містити довільну кількість товарів.
    
- Кожен [[Product]] має унікальний ID.
    
- Список може бути порожнім.
    
- Дані зберігаються між запусками програми.
    

## Основні операції

- Додавання товарів.
    
- Перегляд списку.
    
- Зміна статусу покупки.
    
- Видалення товарів.
    
- Фільтрація за статусом.
    

## Зв'язки

- Список складається з об'єктів [[Product]].
    
- Операції виконує [[ShopLogic]].
    
- Постійне зберігання забезпечує [[DataStorage]].
