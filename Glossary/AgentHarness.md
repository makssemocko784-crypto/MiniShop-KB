# Agent Harness

Agent Harness — інженерна інфраструктура, що забезпечує керовану, відтворювану та контрольовану роботу AI-агента під час розробки програмного застосунку.

## Призначення

У проєкті MiniShop Agent Harness використовується для підтримки розробки за допомогою Codex у VS Code.

## Основні компоненти

- Knowledge Layer — структурована база знань Obsidian.
    
- MCP — механізм доступу агента до зовнішніх інструментів і бази знань.
    
- Skills — формалізовані процедури виконання повторюваних задач.
    
- Guardrails — правила дозволених та заборонених дій агента.
    
- Hooks — механізми технічного контролю дій агента.
    
- Orchestration — координація роботи кількох агентних ролей.
    
- Evaluation — перевірка якості та надійності роботи агента.
    

## Цільові задачі

1. Генерація програмного коду.
    
2. Створення автоматизованих тестів.
    
3. Перевірка якості коду.
    
4. Оновлення документації та бази знань.
