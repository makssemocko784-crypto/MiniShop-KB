# Консольний інтерфейс (CLI)

CLI (Command Line Interface) — компонент застосунку MiniShop, що забезпечує взаємодію користувача з програмою через консоль.

## Призначення

Відображення меню, отримання команд користувача та виведення результатів виконання операцій.

## Основні функції

- Відображення списку доступних команд.
    
- Отримання назви та кількості товару.
    
- Виведення списку покупок.
    
- Передача команд на виконання.
    
- Відображення повідомлень про помилки.
    

## Архітектурні особливості

CLI відповідає лише за взаємодію з користувачем. Обробка товарів і робота з файлами виконуються окремими компонентами.

## Зв'язки

- CLI передає команди до [[ShopLogic]].
    
- CLI відображає об'єкти [[Product]].
    
- Використання консольного інтерфейсу визначено рішенням [[CLIArchitecture]].
