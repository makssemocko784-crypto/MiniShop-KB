# Збереження даних (Data Storage)

DataStorage — компонент MiniShop, відповідальний за збереження та завантаження списку покупок у локальному JSON-файлі.

## Основні функції

- Збереження поточного списку покупок у JSON.
    
- Завантаження раніше збережених товарів.
    
- Перевірка структури та коректності даних.
    
- Обробка помилок читання і запису.
    

## Правила роботи

- Після успішної зміни списку дані автоматично зберігаються.
    
- Якщо JSON-файл відсутній, використовується порожній список.
    
- Якщо файл пошкоджений, користувач отримує повідомлення про помилку.
    
- Пошкоджений файл не перезаписується автоматично.
    
- Після помилки завантаження поточний список залишається незмінним.
    

## Архітектурні особливості

Компонент відповідає лише за роботу з файлами та не реалізує консольний інтерфейс.

## Зв'язки

- Зберігає [[ShoppingList]] та об'єкти [[Product]].
    
- Використовується компонентом [[ShopLogic]].
    
- Формат збереження визначено рішенням [[JSONStorage]].
